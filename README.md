# Ube Supply Demand Gap Analysis
Uber Supply Demand Gap Analysis using Python, EDA and Excel  Dashboard

## Project Overview

This project analyzes Uber ride requests to identify supply-demand gaps, request patterns, cancellations, and unavailable-cab situations.

The analysis was performed using Python for Exploratory Data Analysis (EDA) and Excel for dashboard creation.

## Objectives

- Analyze Uber ride request patterns.
- Identify demand variations by time of day.
- Compare requests between Airport and City pickup points.
- Analyze trip status including completed, cancelled, and no-cars-available requests.
- Identify supply-demand gaps.
- Provide business recommendations to improve driver availability and customer experience.

## Key Insights

- A significant number of ride requests were not successfully completed.
- "No Cars Available" represents a major supply-side issue.
- Demand varies significantly throughout the day.
- Airport and City pickup points show different request patterns.
- Peak-demand periods require better driver availability.
- Night and early-morning periods show important supply-demand gaps.

## Dashboard

The Excel dashboard provides analysis of:

- Total Requests
- Requests by Status
- Requests by Pickup Point
- Requests by Request Hour
- Pickup Point vs Status
- Interactive filters for Pickup Point and Status

## Business Recommendations

- Increase driver availability during peak-demand hours.
- Provide incentives for drivers during high-demand periods.
- Improve driver allocation between Airport and City locations.
- Introduce incentives for night and early-morning shifts.
- Use historical request patterns to forecast demand.
- Monitor cancelled and unfulfilled requests regularly.

## Project Deliverables

- Python EDA Notebook

## Conclusion

The analysis highlights a clear supply-demand imbalance in Uber ride requests. Improving driver availability during high-demand periods and optimizing driver allocation can reduce cancelled and unfulfilled requests and improve customer satisfaction.
